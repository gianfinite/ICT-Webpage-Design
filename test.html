How to Use it


  1. Open the circuit using the Insert the Cirsuitverse link here to open directly link and launch the simulator.
  2. Set the 16-bit input A (bit 0 is the rightmost bit).
  3. Set the 16-bit input B in the same bit order.
  4. Set M to 0 for addition or 1 for subtraction.
  5. Read the 16-bit result and the Cout output (and Borrow, if your circuit has it).
  6. In subtraction mode, Cout = 0 means a borrow occurred (A < B).

Worked Examples


Example 1: Addition with carry (M = 0)

  • Inputs: A = FFFF (1111 1111 1111 1111) = 65,535; B = 0001 = 1

  • Expected: result 0000, Carry 1

  • Observed: result 0000, Carry 1 (confirm in CircuitVerse and edit if different)

  • Meaning: the full 17-bit sum is 1 0000 0000 0000 0000 = 65,536. The 16-bit result alone shows 0, and the carry is the 17th bit.


Example 2: Subtraction with borrow (M = 1)

  • Inputs: A = 0003 (0000 0000 0000 0011) = 3; B = 0005 (0000 0000 0000 0101) = 5

  • Expected: result FFFE, Borrow 1 (Cout = 0)

  • Observed: result FFFE, Borrow 1 (confirm in CircuitVerse and edit if different)

  • Meaning: FFFE is 65,534 unsigned. Subtracting 65,536 gives −2, which is 3 − 5.
